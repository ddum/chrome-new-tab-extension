# NewTab - Расширение для новой вкладки Chrome

Расширение для браузера Chrome, которое заменяет стандартную страницу новой вкладки.

## Основные функции

- 🕐 **Отображение времени** - Большие часы в центре экрана
- 🔗 **Управление ссылками** - Добавляйте и организуйте свои избранные сайты
- 🖼️ **Настраиваемый фон** - Устанавливайте фоновые изображения
- 💾 **Импорт/Экспорт** - Сохраняйте и восстанавливайте свои настройки

## Технологии

- **Vue 3** - Современный JavaScript-фреймворк
- **TypeScript** - Типобезопасность
- **Pinia** - Управление состоянием
- **Vite** - Сборка проекта
- **Vitest** - Тестирование

## Установка в браузер

1. Выполните сборку проекта: `npm run build`
2. Откройте Chrome и перейдите по адресу `chrome://extensions/`
3. Включите "Режим разработчика"
4. Нажмите "Загрузить распакованное расширение" и выберите папку сборки
